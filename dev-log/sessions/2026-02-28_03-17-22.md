+## 電話のかけ方
+
+### 前提条件
+
+- セットアップ（手順 1〜5）が完了していること
+- ngrok が起動中で `PUBLIC_URL` が設定されていること
+- Twilio トライアルアカウントの場合、発信先は Verified Numbers に登録済みの番号のみ
+
+### 手順
+
+**1. ヘルスチェックでアプリが起動しているか確認**
+
+```bash
+curl http://localhost:3000/health
+```
+
+**2. 電話を発信**
+
+```bash
+curl -X POST http://localhost:3000/api/make-call \
+  -H "Content-Type: application/json" \
+  -d '{"to": "+819012345678"}'
+```
+
+`to` には E.164 形式（`+` + 国番号 + 番号）で相手の電話番号を指定する。
+
+**3. 相手が電話に出る**
+
+- Twilio トライアルアカウントの場合、自動音声で「Press any key to continue」と流れる

+**4. AI との会話が始まる**
+
+キーを押すと、裏側で以下が自動的に起きる:
+
+1. Twilio がサーバーの `/api/twiml` を呼び出す
+2. サーバーが TwiML（`<Connect><Stream>`）を返す
+3. Twilio が `/api/media-stream` に WebSocket 接続する
+4. サーバーが ElevenLabs Conversational AI に WebSocket 接続する
+5. ElevenLabs AI が日本語で話し始め、双方向のリアルタイム音声通話になる

+```bash
