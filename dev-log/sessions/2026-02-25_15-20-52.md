 # ai-outbound-calling
+
+AI を使った電話営業の自動化システム。Twilio で発信し、AI 音声で会話を行う。
+
+## 必要なもの
+
+- Docker / Docker Compose
+- ngrok アカウント（https://ngrok.com）
+- Twilio アカウント（https://www.twilio.com）
+
+## セットアップ
+
+### 1. リポジトリをクローン
+
+```bash
+git clone https://github.com/LlechiKaito/ai-outbound-calling.git
+cd ai-outbound-calling
+```
+
+### 2. 環境変数を設定
+
+```bash
+cp .env.example .env
+```
+
+`.env` を編集して以下の値を設定する:
+
+```
+PORT=3000
+HOST=0.0.0.0
+PUBLIC_URL=              # 手順 4 で ngrok を起動した後に設定する
+
+TWILIO_ACCOUNT_SID=ACxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
+TWILIO_AUTH_TOKEN=xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
+TWILIO_PHONE_NUMBER=+1xxxxxxxxxx
+```
+
+Twilio の値は https://console.twilio.com で確認できる。
+
+### 3. Docker イメージをビルド
+
+```bash
+docker compose build app
+```
+
+### 4. ngrok を起動して公開 URL を取得
+
+別のターミナルで:
+
+```bash
+ngrok http 3000
+```
+
+表示された URL（例: `https://xxxx-xx-xx.ngrok-free.app`）を `.env` の `PUBLIC_URL` に設定する:
+
+```
+PUBLIC_URL=https://xxxx-xx-xx.ngrok-free.app
+```
+
+ngrok を止めるときは `Ctrl+C`。プロセスが残った場合は `pkill ngrok`。
+
+### 5. アプリを起動
+
+```bash
+docker compose up app
+```
+
+バックグラウンドで起動したい場合:
+
+```bash
+docker compose up app -d
+```
+
+### 6. 動作確認
+
+ヘルスチェック:
+
+```bash
+curl http://localhost:3000/health
+```
+
+期待されるレスポンス:
+
+```json
+{"isSuccess":true,"data":{"status":"ok"}}
+```
+
+電話を発信（E.164 形式の電話番号を指定）:
+
+```bash
+curl -X POST http://localhost:3000/api/make-call \
+  -H "Content-Type: application/json" \
+  -d '{"to": "+8190XXXXXXXX"}'
+```
+
+期待されるレスポンス:
+
+```json
+{
+  "isSuccess": true,
+  "data": {
+    "callSid": "CAxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx",
+    "to": "+8190XXXXXXXX",
+    "from": "+1xxxxxxxxxx",
+    "status": "queued"
+  }
+}
+```
+
+TwiML エンドポイントの確認:
+
+```bash
+curl -X POST http://localhost:3000/api/twiml
+```
+
+期待されるレスポンス（XML）:
+
+```xml
+<?xml version="1.0" encoding="UTF-8"?>
+<Response><Say language="ja-JP">こんにちは。お電話ありがとうございます。</Say></Response>
+```
+
