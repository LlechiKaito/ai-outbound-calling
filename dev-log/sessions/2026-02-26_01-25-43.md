 # ai-outbound-calling
+
+AI を使った電話営業の自動化システム。Twilio で発信し、ElevenLabs Conversational AI がリアルタイムで自然な声で会話を行う。
+
+## 必要なもの
+
+- Docker / Docker Compose
+- ngrok アカウント（https://ngrok.com）
+- Twilio アカウント（https://www.twilio.com）
+- ElevenLabs アカウント（https://elevenlabs.io）
+
+## セットアップ
+
+### 1. リポジトリをクローン
+
+```bash
+git clone https://github.com/LlechiKaito/ai-outbound-calling.git
+cd ai-outbound-calling
+```
+
+### 2. 環境変数を設定
+
+```bash
+cp .env.example .env
+```
+
+`.env` を編集して以下の値を設定する:
+
+```
+PORT=3000
+HOST=0.0.0.0
+PUBLIC_URL=              # 手順 4 で ngrok を起動した後に設定する
+
+TWILIO_ACCOUNT_SID=ACxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
+TWILIO_AUTH_TOKEN=xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
+TWILIO_PHONE_NUMBER=+1xxxxxxxxxx
+
+ELEVENLABS_API_KEY=xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
+ELEVENLABS_AGENT_ID=xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
+```
+
+- Twilio の値は https://console.twilio.com で確認できる
+- ElevenLabs の値は https://elevenlabs.io/app/settings で API Key、Conversational AI ダッシュボードで Agent ID を確認できる
+
+### 3. Docker イメージをビルド
+
+```bash
+docker compose build app
+```
+
+### 4. ngrok を起動して公開 URL を取得
+
+別のターミナルで:
+
+```bash
+ngrok http 3000
+```
+
+表示された URL（例: `https://xxxx-xx-xx.ngrok-free.app`）を `.env` の `PUBLIC_URL` に設定する:
+
+```
+PUBLIC_URL=https://xxxx-xx-xx.ngrok-free.app
+```
+
+ngrok を止めるときは `Ctrl+C`。プロセスが残った場合は `pkill ngrok`。
+
+### 5. アプリを起動
+
+```bash
+docker compose up app
+```
+
+バックグラウンドで起動したい場合:
+
+```bash
+docker compose up app -d
+```

+
+ヘルスチェック:
+
+```bash
+curl http://localhost:3000/health
+```
+
+期待されるレスポンス:
+
+```json
+{"isSuccess":true,"data":{"status":"ok"}}

+## API エンドポイント一覧
+
+| メソッド | パス | 説明 |
+|---------|------|------|
+| GET | `/health` | ヘルスチェック |
+| POST | `/api/make-call` | 電話を発信する |
+| POST | `/api/twiml` | Twilio Webhook 用の TwiML を返す |
+| GET | `/api/media-stream` | Twilio Media Stream 用 WebSocket エンドポイント |
+
+### POST /api/make-call
+
+リクエスト:
+
+```json
+{
+  "to": "+819012345678"
+}
+```
+
+電話番号は E.164 形式（`+` + 国番号 + 番号）で指定する。
+
+### GET /api/media-stream（WebSocket）
+
+Twilio Media Stream と ElevenLabs Conversational AI を中継する WebSocket エンドポイント。直接呼び出すのではなく、Twilio が TwiML の `<Connect><Stream>` 指示に基づいて自動的に接続する。
+
+音声フォーマット: μ-law 8000 Hz（入出力とも）
+
+## 通話フロー
+
+```
+1. POST /api/make-call → Twilio が電話を発信
+2. 相手が応答 → Twilio が POST /api/twiml を呼び出し
+3. TwiML で <Connect><Stream> を返却
+4. Twilio が /api/media-stream に WebSocket 接続
+5. サーバーが ElevenLabs Conversational AI に WebSocket 接続
+6. 音声が双方向にリアルタイム中継される
+```
+
